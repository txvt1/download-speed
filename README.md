# download-speed

Консольный скрипт на Python для замера скорости скачивания.

Скрипт делает **10 последовательных запросов** к указанному адресу, на каждый дожидается полного ответа (тело читается до конца), затем выводит:

- время и объём каждого запроса;
- **среднее время запроса**, секунды;
- **общий объём скачанных данных**, байты (и в удобных единицах);
- **скорость скачивания**.

## Единицы измерения

| Величина | Единица |
|---|---|
| Время | секунды (с) |
| Объём | байты; для удобства также КБ/МБ/ГБ (десятичные: 1 МБ = 1 000 000 байт) |
| Скорость (основная) | **МБ/с** — мегабайты в секунду, 1 МБ = 1 000 000 байт |
| Скорость (справочно) | Мбит/с — мегабиты в секунду (МБ/с × 8), как обычно указывают провайдеры |

Скорость считается как `общий объём / суммарное время всех запросов`.

## Требования

- Python 3.9 или новее
- Сторонние библиотеки не нужны, только стандартная библиотека

## Запуск

```bash
git clone https://github.com/<ваш-логин>/download-speed.git
cd download-speed
python3 speedtest.py <URL>
```

Пример:

```bash
python3 speedtest.py https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
```

На Windows вместо `python3` используйте `python` или `py`.

### Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| `url` | — | адрес, к которому стучаться (обязательный) |
| `-n`, `--count` | 10 | число запросов |
| `-t`, `--timeout` | 60 | таймаут одного запроса, с |

## Пример вывода

```
URL: https://example.com/big.jpg
Запросов: 10

Запрос  1:    5.24 МБ  за   0.512 с  (10.24 МБ/с)
Запрос  2:    5.24 МБ  за   0.498 с  (10.53 МБ/с)
...
Запрос 10:    5.24 МБ  за   0.505 с  (10.38 МБ/с)

--- Итог ---
Среднее время запроса: 0.503 с
Всего скачано:         52428800 байт (52.43 МБ)
Скорость скачивания:   10.42 МБ/с (83.38 Мбит/с)
```

## Замечания

- Запросы идут строго по очереди: следующий начинается только после полного получения предыдущего ответа.
- Отправляются заголовки `Cache-Control: no-cache` и `Accept-Encoding: identity`, чтобы не получать ответ из кеша и считать реальные байты без сжатия. CDN могут игнорировать `no-cache`.
- Время запроса включает установку соединения (DNS, TCP, TLS) и ожидание первого байта, то есть отражает то, что видит пользователь.
- При ошибке HTTP или сети скрипт печатает её и завершается с кодом 1.
